# IFLS Food Classifier — Project Context

## What this project does
Classifies food product names into the IFLS taxonomy, a 4-level hierarchy:
GROUP > FAMILY > SUBFAMILY > SEGMENT (~1000 segments, ~200k products).

The model predicts the segment ID from a raw product name string.
The full classification path (group/family/subfamily) is then resolved from
the segment ID via a database lookup — the model only needs to return segment_id.

## Architecture
- Backbone: DistilBERT (distilbert-base-uncased) fine-tuned with LoRA
- 4 classification heads (one per IFLS level), trained jointly
- Combined loss: weighted sum of FocalLoss per level
- Hierarchical sampler: samples segments uniformly (not products) to handle imbalance
- Cascaded inference: each level constrains valid candidates for the next
- Temperature scaling: post-hoc confidence calibration on a held-out split

## Data
- CSV: data/products.csv
- Columns: product_name (str), group_id (long), family_id (long), subfamily_id (long), segment_id (long)
- IDs are arbitrary DB primary keys (not contiguous) — HierarchyEncoder maps them to 0-based indices internally
- hierarchy.json is generated by training, never hand-edited

## Project structure
- ifls/          — importable library, no side-effects, fully tested
- scripts/       — thin entry points (train.py, predict_batch.py)
- config/        — all hyperparameters in base.yaml, no magic numbers in code
- tests/         — CPU-only, ~30s, run with pytest
- models/        — gitignored checkpoints, tracked separately
- data/          — raw CSV + generated artifacts (hierarchy.json, encoders)

## Key design decisions
- LevelEncoder maps DB long IDs ↔ contiguous model indices
- HierarchyEncoder owns the tree (parent_to_children, child_to_parent)
- predict_batch.py returns DB IDs (not indices) — callers never see model internals
- Temperature scaler is fitted on a separate calibration split (not eval)
- LoRA task_type is FEATURE_EXTRACTION (not SEQ_CLS) — heads are managed manually

## Environment
- Python venv at .venv/ (always activate before running anything)
- Install: pip install -e ".[dev]"
- Run tests: pytest
- Train: python scripts/train.py --config config/base.yaml
